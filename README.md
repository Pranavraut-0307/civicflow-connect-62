# Civitas Hub

Build a modern civic-tech web application called "CivilFlow".

CivilFlow is a smart civic issue reporting and monitoring platform for citizens and municipal authorities.

GOAL:

Citizens should be able to report civic problems such as potholes, damaged roads, garbage, drainage problems, broken streetlights and water leakage. Authorities should be able to monitor, prioritize and resolve these issues.

Create a professional, modern, clean dashboard-style UI.

PAGES:

1. Landing Page

- CivilFlow logo/name

- Short tagline: "Report. Track. Improve."

- Explain how CivilFlow works

- Citizen Login button

- Authority Login button

- Statistics section

- Modern civic-tech visual design

2. Citizen Dashboard

- Total reports

- Pending reports

- Resolved reports

- Recent reports

- "Report an Issue" primary button

- Small map showing reported issues

3. Report Issue Page

Fields:

- Issue category

  - Pothole

  - Road Damage

  - Garbage

  - Drainage

  - Broken Streetlight

  - Water Leakage

  - Other

- Upload image

- Description

- Location

- GPS/location button

- Submit Report button

4. Complaint Tracking Page

- Complaint ID

- Issue type

- Location

- Date reported

- Current status

- Timeline:

  Reported → Verified → Assigned → In Progress → Resolved

5. Interactive Map Page

- Map of Nagpur

- Issue markers

- Different issue categories

- Filter by category

- Filter by status

- Search location

6. Authority Dashboard

- Total complaints

- Critical complaints

- Pending complaints

- Resolved complaints

- Complaint table

- Priority levels

- Status management

- Map view

- Analytics cards/charts

7. Complaint Details Page

- Complaint information

- Uploaded image

- Location

- AI analysis section placeholder

- Severity score placeholder

- Duplicate report indicator placeholder

- Status update controls

DESIGN:

- Modern government/civic technology style

- Professional and trustworthy

- Clean cards

- Responsive layout

- Excellent spacing

- Accessible typography

- Subtle animations

- Desktop and mobile responsive

IMPORTANT:

For now create the frontend prototype and realistic mock data.

Do NOT build fake AI functionality.

Create clear placeholders/components where AI detection, duplicate detection and severity scoring will later be connected to a real backend API.

Use reusable components and maintain a clean project structure.
